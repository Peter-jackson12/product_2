# product_2

제품 데이터 분석 수업의 실습·과제 저장소입니다. 각 Jupyter Notebook에는 필수 실습과 제출용 **과제 1**이 함께 들어 있습니다.

## 환경

- Python 3.11+
- 패키지/가상환경 관리: [uv](https://docs.astral.sh/uv/)
- 주요 의존성: pandas, numpy, matplotlib, jinja2
- 프로젝트 의존성은 `pyproject.toml`과 `uv.lock`으로 관리합니다.

```bash
uv sync
```

VS Code/Jupyter에서 프로젝트의 `.venv` 인터프리터를 커널로 선택해 노트북을 위에서부터 순서대로 실행합니다. 패키지를 추가할 때는 재현성을 위해 `pip install`보다 `uv add <package>`를 기본으로 사용합니다.

## 노트북 구성

- 1장 2강: 좋은 지표의 조건
- 2장 1강: AARRR 프레임워크
- 2장 2강: 퍼널 분석
- 2장 3강: 코호트 기반 리텐션·세그멘테이션
- 2장 4강: 이벤트 로그 기반 AARRR·퍼널
- 2장 5강: A/B 테스트와 실험 설계 오류
- 3장 1강: 프로젝트 개요와 문제 정의
- 3장 2강: 퍼널·리텐션 개선 시나리오

## 데이터

`data/`에는 수업 실습용 데이터가 있습니다. RavenStack 데이터는 **River @ Rivalytics**가 만든 합성 교육용 데이터이며 실제 사업 성과로 일반화하지 않습니다. 상세 출처·스키마·라이선스는 `data/README.md`를 확인하세요.

## 분석 시 공통 원칙

- 반복 이벤트 수와 고유 사용자/계정/구독 수를 구분합니다.
- 퍼널은 이전 단계 도달 집합을 분모로 사용하고 단계 순서를 확인합니다.
- 리텐션은 코호트 기준·경과 시간·관찰 가능 기간을 명시합니다.
- 아직 관찰할 수 없는 기간을 0%로 처리하지 않습니다.
- 세그먼트 차이와 퍼널의 낮은 전환율은 원인 자체를 증명하지 않습니다.
- 관찰된 사실 → 원인 가설 → 추가 분석/실험의 순서를 유지합니다.
- A/B 테스트는 목표 지표·배정 방식·표본 크기·기간을 결과 확인 전에 정합니다.

> 노트북에 저장된 출력은 작성 시점의 실행 결과입니다. 환경이나 코드가 바뀐 경우 제출 전 커널을 재시작하고 위에서부터 다시 실행해 출력과 소스가 일치하는지 확인하세요.
